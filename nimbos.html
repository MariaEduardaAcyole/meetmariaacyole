A Solução

O NIMBOS é uma solução baseada em Edge Computing e Internet das Coisas, desenvolvida para capturar informações do ambiente através de sensores conectados. O sistema realiza aquisição de dados físicos, processamento local e transmissão utilizando protocolo MQTT, permitindo monitoramento em tempo real e integração com aplicações inteligentes.

Objetivo

Criar um sistema IoT capaz de coletar dados utilizando sensores embarcados, promovendo monitoramento inteligente e comunicação eficiente entre dispositivos para previnir enchentes causadas por bueiros entupidos.

Aplicação-alvo

Soluções inteligentes envolvendo automação, monitoramento ambiental, gestão de recursos e aplicações baseadas em Internet das Coisas.

Resultado

Protótipo funcional integrando hardware, sensores, comunicação MQTT e coleta de dados em tempo real.

Funcionalidades

🌱

Coleta de Dados

Monitoramento de informações físicas através de sensores conectados, permitindo captura de peso, fluxo e informações do ambiente em tempo real.

⚙️

Processamento Edge

Sensor de vazão para medir a quantidade de água passando e o sensor de peso para entender o quanto o bueiro pode ficar entupido em um futuro.

📡

Comunicação IoT

Transmissão dos dados utilizando protocolo MQTT através do ESP8266 integrado ao broker HiveMQ.

⚖️

Medição de Carga

Utilização de célula de carga com módulo HX711 para aquisição precisa de dados relacionados à força e peso.

💧

Monitoramento de Fluxo

Sensor de fluxo responsável pela coleta de informações sobre passagem e consumo de líquidos.

🧪

Prototipação Virtual

Desenvolvimento e validação do circuito eletrônico utilizando ambiente de simulação TinkerCad.

🔗

Integração Hardware

Conexão entre sensores, microcontroladores e serviços IoT formando uma solução embarcada completa.

Resultado do Projeto

O NIMBOS resultou no desenvolvimento de um protótipo IoT funcional, integrando sensores, microcontroladores e comunicação em nuvem para monitoramento inteligente de bueiros. O projeto proporcionou experiência prática em sistemas embarcados, Edge Computing, protocolos de comunicação e integração entre hardware e software para prevenção de desastres naturais.
